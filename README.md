# Transformation Lab — Math 172 / FN4

This is the complete interactive Transformation Lab website, ready for GitHub and Netlify.

## Files

- index.html — the website entry page
- style.css — the layout, colors, and presentation view
- app.js — graphs, seven lessons, exploration controls, and 37 practice questions
- netlify.toml — static publishing configuration
- README.md — these instructions

## Upload to GitHub

1. Extract this ZIP on your computer.
2. Create or open the repository you want to use for this app.
3. Upload all FIVE extracted files directly into the repository's main level.
4. Confirm that index.html is visible when you first open the repository. It should sit alongside app.js, style.css, netlify.toml, and README.md.
5. Commit the upload.

Do not upload the ZIP itself as the website. No nested folders are required.

## Deploy on Netlify

Import the GitHub repository as a Netlify project. Use these settings if requested:

| Setting | Value |
| --- | --- |
| Base directory | Leave blank |
| Build command | Leave blank |
| Publish directory | . (a single period) |

The included netlify.toml sets the publish directory to the repository root. This app is plain HTML, CSS, and JavaScript, so there is no installation or build step. It needs no API keys, database, or environment variables.

After deployment, open the Netlify URL and check Learn & teach, Explore, and Quick practice. Use that URL when sharing the app with students or linking from Canvas.

Official Netlify configuration reference:
https://docs.netlify.com/build/configure-builds/file-based-configuration/

## Open locally

Open index.html in a modern browser. The app and its graphing features run locally; the course-resource links need an internet connection. Practice results last for the current page session.
